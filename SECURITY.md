# Security policy

crawlerpeek fetches URLs on behalf of its user, so request-forgery protections (private address blocking, redirect re-checks, size and time limits) are in scope, as is anything in the MCP server that could be abused by a prompt.

## Reporting a vulnerability

Please use [private vulnerability reporting](https://github.com/crawlerpeek/crawlerpeek/security/advisories/new) on GitHub, or email hello@crawlerpeek.com. Do not open a public issue. You will get an answer within a few days.

## Supported versions

Only the latest release receives fixes.
